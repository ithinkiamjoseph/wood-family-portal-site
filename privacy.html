Wood Family Portal — Privacy Policy

Wood Family Portal is a private, single-household dashboard. It is used only by the family that runs it.

What it reads

With the family's permission, it reads the family Google account's calendar events and email headers (sender, subject and unread count) using read-only access. It cannot send, change or delete anything.

Where the data goes

The data is shown on a screen inside the family's home and is processed on a computer the family owns. It is not sold, shared with anyone, or used for advertising. Short-lived copies are kept in memory only so the screen can refresh.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from the Google account's third-party access settings.
